# Проект: Обработка транзакций

## Описание
Проект содержит набор функций для работы с банковскими транзакциями.

Реализованы три генератора:
- **`filter_by_currency`** — фильтрация транзакций по заданной валюте
- **`transaction_descriptions`** — получение описаний каждой транзакции
- **`card_number_generator`** — генерация номеров банковских карт в заданном диапазоне
