Проект "Домашняя работа"
Описание:
Проект "Домашняя работа" - это функционал, который принимает на входе от пользователя номер карты и счета и выводит его маску, так же выводит тип карты или счета и маску, меняет формат введенный пользователем даты, фильтрует списки со словарями и сортирует словари по убыванию даты, так же есть тесты для функций, содержит набор функций для работы с банковскими транзакциями.

Установка:
Клонируйте репозиторий:
git clone git@github.com:gulisalikhova-cmyk/homework_1.git
Установите зависимости:
pip install -r requirements.txt
Использование:
Перейдите на страницу в вашем веб-браузере.
Создайте новую учетную запись или войдите существующей.
Создайте новую запись в блоге или оставьте комментарий к существующей.
